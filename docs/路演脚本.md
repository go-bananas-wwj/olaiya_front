# 颜鉴路演脚本

> 2026-10-16：以「看构成 → 找相似、比价格 → 圆桌解释证据」为主线，保留详细功能。

## 8 分钟版

### 0:00–1:00 开场

「一瓶护肤品有什么成分？类似构成的产品卖多少钱？它的功效宣称有多少证据撑得住？颜鉴把这三个问题放在一起回答，每个不确定都明确展示。」

### 1:00–3:00 看懂成分

搜索预先核实的产品，打开完整成分表。说明已知位次按来源展示，未知位次不会编造。点击一个成分，进入用途、证据与含该成分产品的档案。说明分类、安全、供应商资料不等于临床功效实证。

### 3:00–5:00 找相似、比价格

在同一产品页切换「成分重合」和「嵌入相似」，展开共有与差异成分，查看价格、规格及来源。按价格重排时说明只是本次候选池；无价格明确显示缺失。进入双产品对比，展示共有 / 不同成分、价格和证据差异。元/g 和元/ml 不互换，相似不代表功效相同。

### 5:00–7:00 圆桌解释证据

从产品详情发起圆桌，沿用选中的产品版本。四角色分别解释产品构成、备案宣称、文献与剂量数据；展开裁决下的引用资料。浓度是估计，文献研究浓度不自动等于成品起效门槛；证据或模型缺失时明确提示。

### 7:00–8:00 收尾

「颜鉴让用户看清产品构成、比较相似候选的价格，并沿着圆桌解释追到证据。不能确定的地方，我们保留未知。」展示已核实的测试结果与数据覆盖边界；不把内部回归集分数描述为临床有效性或普遍准确率。

## 3 分钟版

1. 30 秒：提出构成、价格、证据三个问题。
2. 45 秒：完整成分表 → 成分来源。
3. 45 秒：相似候选 → 双产品价格与成分对比。
4. 45 秒：四角色圆桌 → 引用资料。
5. 15 秒：说明未知、估计与覆盖范围。

## 常见追问

ModelScope 单页演示可直接点击「黑绷带 / A.G.E.」或「Serum 10 / C E Ferulic」，在同页切换相似方式、点击共有成分展开证据，并分别核验参照／对照产品。案例仅为构成和价格对照，不宣称功效等价；账号推理权限未满足时，展示圆桌不可用提示，不演示虚构发言。

- **浓度准确吗？** 输出是约束采样的估计区间，当前仅部分产品具备推断结果；不能替代实测。
- **成分一样就效果一样吗？** 不会这样承诺，配方含量、剂型、递送和研究适用条件仍可能不同。
- **价格实时吗？** 价格是带来源和记录日期的参考值，促销、规格和渠道可能不同。
- **有出处就是真的吗？** PMID 标题核验只确认文献身份，内容支持性与适用性仍需审核；分类、安全与营销资料不会被表述为临床实证。
- **为什么需要圆桌？** 展示不同信息来源与不确定性；其相对单模型的收益仍需同预算评测。

## 演示前检查

- 确认 8008 网页、8100 本地 LLM（或已配置的云端通道）在线；使用图片检测时另查 8101。
- 预跑一个产品圆桌，记录实际延迟，不承诺固定 30 秒。
- 准备有成分表、来源可查的演示产品，以及无价格、无浓度两类缺失场景。
- 模型不可达时展示真实错误提示；预录结果需明确标为回放，不冒充实时输出。
