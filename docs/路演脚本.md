# 颜鉴路演脚本

> 2026-10-19（北京时间）：ModelScope主线为「产品空间 / 两款对比」。产品空间采用Google Embedding Projector式真实高维降维与点选交互，主流程不使用聊天或圆桌。

## 三分钟主演示

1. **0:00–0:30：看见空间。**「这里每个点是一款护肤品。我们把3749款产品的4096维成分向量，投影成可以旋转的三维空间。」拖动旋转、切二维；指出顶部两款对比入口。
2. **0:30–1:05：点选与近邻。** 搜索或点选黑绷带，看到背景降灰、选中点突出、100个原空间近邻金橙色，右侧列表与距离同步。「画面帮助探索，候选按原始向量检索；相近不代表功效等同。」
3. **1:05–1:30：隔离看细节。** 点击隔离、放大、恢复全库；将数量调5，再切Serum10，展示紧密邻居仍可清楚选择。相同投影点用逐款列表。
4. **1:30–2:05：两款八维。** 点击近邻“比较”，第一屏完整八方向；可切两个真实案例，搜索替换任意A/B。「这是成分功效证据指数，不是成品实测；资料不足不补零。」
5. **2:05–2:40：贡献与原始来源。** 点击保湿，再查看成分来源，说明研究场景和局限，工具书是行业参考；浓度估计与披露分开。需要时展开共有／独有成分和历史单价。
6. **2:40–3:00：返回与透明度。** 返回产品空间保留选择，展示手机抽屉。「三维UMAP只保留约49.5%的原始10近邻；PCA三轴解释约15.47%方差，所以我们把真实距离和证据留在旁边，让用户核对。」

## 备用操作

- 按品牌或证据着色、改变点大小、切PCA轴；颜色不替代产品身份和数值。
- 手机“搜索与近邻”抽屉可选产品、调整数量、隔离或比较；工具不挤出画布。
- 无WebGL时显示真实不可用状态和重试，搜索／对比入口仍可使用；不把二维补Z伪装三维。

## 常见追问

- **指数高就是更有效吗？** 指数反映按既定规则汇总的已收录成分证据贡献，受资料覆盖影响，不能替代成品功效验证。
- **为什么没有百分制总分？** 当前资料不能支持普遍适用的产品综合能力评分；我们逐方向展示原始参考指数及来源。
- **为什么某项显示资料不足？** 当前没有合格资料可计入该方向，不代表该产品没有该功效。
- **为什么浓度不直接乘进主指数？** 全库浓度覆盖有限；首版把浓度作为独立资料维度，避免把缺数据直接解释为能力差。进一步浓度对照仍基于已有剂量服务，并保留估计语义。
- **同一篇研究会不会重复算？** 同成分、同方向多条断言只取最高合格权重；来源数量按证据 ID 去重。不同成分引用同一来源的情况可在贡献明细看到，不能将其误读为多项独立临床研究。
- **价格实时吗？** 是带来源与记录日期的历史参考值；不同单位不换算比较。
- **AI 在哪里？** 主展示强调可复算的证据指数与来源链；预计算嵌入用于相似检索。原站还保留问答与圆桌能力，展示页不要求用户与模型聊天。

## 演示前检查

- 确认私有创空间为 Running，并用所属账号登录；使用本地展示时确认 8008 API 与展示预览在线。
- 预跑两组真实案例，确认八方向、来源与单价；核对仍使用固定数据快照和 `evidence-index-v1`。
- 不承诺实时价格、全量证据覆盖或临床准确率；没有原文链接时如实说明。
- 保留“未评级”“资料不足”“浓度无法判断”“暂无价格”等缺失场景，不用虚构数据填图。
