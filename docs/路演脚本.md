# 颜鉴路演脚本

> 2026-10-18：ModelScope 主线为「全库地图 → 选任意产品 → 看八方向证据 → 查来源 → 任意两款对比」。全程点击和搜索，主流程不使用聊天或圆桌。

## 3 分钟版

1. **0:00–0:25：看见全库。**「每个点，一款产品。颜鉴把库里的3749款护肤品放在同一张成分表语义地图里，先探索，再核对证据。」
2. **0:25–1:00：定位一款。** 搜索黑绷带面霜，展开八方向证据画像。说明图上的位置只用于探索，空间相近不代表功效等同；相似检索按原始4096维，而不是屏幕距离。
3. **1:00–1:45：从维度追到原文。** 点击保湿，再点击来源，展示人体/间接研究场景、权重、备注和原文；估计浓度不是实测值。两次点击完成追溯。
4. **1:45–2:25：任意两款对比。** 将当前产品加入对比，再搜索另一款任意产品加入；并排核对同刻度指数、共享/独有成分、单位可比的历史价格及来源。返回地图保留选择。
5. **2:25–3:00：把未知留出来。** 切换“证据坐标”，选择焕肤与抗氧化，展示未定位集合仍可搜索；不把缺资料放到0点，不输出百分制总分或“效果胜负”。

## 8 分钟版补充内容

- 展开“指数方法与未计入的资料”，说明同成分同方向取最高合格权重，重复记录不会累加；研究来源数量按真实证据 ID 去重。
- 展开“未计入的资料”，展示功能分类、法规、安全和供应商等排除原因。这些资料仍可查阅，但不作为主指数的功效实证。
- 工具书属于低强度行业参考；体外、动物、综述等属于间接资料，复方资料不能表述为单成分独立临床效果；口服研究不计入外用产品指数。
- 从详情点击“按原始向量找相似”，查看候选或加入两款进行对比；匹配方法在说明中展开，相似不代表功效等同。
- 展示手机宽度的同一条操作路径：地图搜索 → 证据画像 → 贡献成分 → 来源。

## 常见追问

- **指数高就是更有效吗？** 指数反映按既定规则汇总的已收录成分证据贡献，受资料覆盖影响，不能替代成品功效验证。
- **为什么没有百分制总分？** 当前资料不能支持普遍适用的产品综合能力评分；我们逐方向展示原始参考指数及来源。
- **为什么某项显示资料不足？** 当前没有合格资料可计入该方向，不代表该产品没有该功效。
- **为什么浓度不直接乘进主指数？** 全库浓度覆盖有限；首版把浓度作为独立资料维度，避免把缺数据直接解释为能力差。进一步浓度对照仍基于已有剂量服务，并保留估计语义。
- **同一篇研究会不会重复算？** 同成分、同方向多条断言只取最高合格权重；来源数量按证据 ID 去重。不同成分引用同一来源的情况可在贡献明细看到，不能将其误读为多项独立临床研究。
- **价格实时吗？** 是带来源与记录日期的历史参考值；不同单位不换算比较。
- **AI 在哪里？** 主展示强调可复算的证据指数与来源链；预计算嵌入用于相似检索。原站还保留问答与圆桌能力，展示页不要求用户与模型聊天。

## 演示前检查

- 确认私有创空间为 Running，并用所属账号登录；使用本地展示时确认 8008 API 与展示预览在线。
- 预跑两组真实案例，确认八方向、来源与单价；核对仍使用固定数据快照和 `evidence-index-v1`。
- 不承诺实时价格、全量证据覆盖或临床准确率；没有原文链接时如实说明。
- 保留“未评级”“资料不足”“浓度无法判断”“暂无价格”等缺失场景，不用虚构数据填图。
