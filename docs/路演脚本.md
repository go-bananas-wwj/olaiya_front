# 颜鉴路演脚本

> 2026-10-19（北京时间）：ModelScope主线为两个同级入口「产品地图 / 两款对比」。先找真实相近候选，或直接比较任意两款，再核对贡献与原始来源。全程点击和搜索，主流程不使用聊天或圆桌。

## 三分钟主演示

1. **0:00–0:25：先交代两个用途。**「颜鉴，一边在全库找成分与证据接近的产品，一边把任意两款的八个方向摆在一起看。」指向两个顶部入口。
2. **0:25–1:00：地图找候选。** 默认黑绷带参照，三个真实候选有编号与连线；切换“成分组成接近/功效证据接近”。「数字圆圈是产品集合数量，放大或展开可逐款选。检索按原始数据，屏幕靠近不等于功效等同。」
3. **1:00–1:40：两款直接对照。** 点候选“与它对比”，A绿色、B暖橙，第一屏完整八方向。「这是成分功效证据指数，不是成品实测效果。资料不足不补零，同分不制造差异。」
4. **1:40–2:15：两次点击追源。** 点击保湿，再点贡献成分“查看来源”，说明研究场景、权重和局限；工具书仅为行业参考，估计不是披露浓度。
5. **2:15–2:45：任意产品与差异。** 搜索替换任意A/B，展示第二组Serum10/C E Ferulic案例、共享/独有成分、历史价格；ml/g不可比时不算优势。
6. **2:45–3:00：返回与收束。** 返回地图，所选A/B保留。「地图帮助发现，对比帮助理解，来源支持核验；没有资料时，明确说不知道。」

## 常见追问

- **指数高就是更有效吗？** 指数反映按既定规则汇总的已收录成分证据贡献，受资料覆盖影响，不能替代成品功效验证。
- **为什么没有百分制总分？** 当前资料不能支持普遍适用的产品综合能力评分；我们逐方向展示原始参考指数及来源。
- **为什么某项显示资料不足？** 当前没有合格资料可计入该方向，不代表该产品没有该功效。
- **为什么浓度不直接乘进主指数？** 全库浓度覆盖有限；首版把浓度作为独立资料维度，避免把缺数据直接解释为能力差。进一步浓度对照仍基于已有剂量服务，并保留估计语义。
- **同一篇研究会不会重复算？** 同成分、同方向多条断言只取最高合格权重；来源数量按证据 ID 去重。不同成分引用同一来源的情况可在贡献明细看到，不能将其误读为多项独立临床研究。
- **价格实时吗？** 是带来源与记录日期的历史参考值；不同单位不换算比较。
- **AI 在哪里？** 主展示强调可复算的证据指数与来源链；预计算嵌入用于相似检索。原站还保留问答与圆桌能力，展示页不要求用户与模型聊天。

## 演示前检查

- 确认私有创空间为 Running，并用所属账号登录；使用本地展示时确认 8008 API 与展示预览在线。
- 预跑两组真实案例，确认八方向、来源与单价；核对仍使用固定数据快照和 `evidence-index-v1`。
- 不承诺实时价格、全量证据覆盖或临床准确率；没有原文链接时如实说明。
- 保留“未评级”“资料不足”“浓度无法判断”“暂无价格”等缺失场景，不用虚构数据填图。
