# 颜鉴路演脚本

> 2026-10-20：当前改版主线为「产品全景 → 按需选品 → 两款对比」。上线状态和数量以实施验收记录及页面实时覆盖为准；数据门槛未达时不称全验收通过。

## 三分钟主演示

1. **0:00–0:25：看见选择范围。**「列表一次只看一款，我们先把产品放到同一张图里。」旋转三维全景，先看上方项目介绍，旋转白色点云中的近大远小层次，说明颜色表示成分语义分区而非功效分类；真实记录数与已有向量数分开统计；点击产品平滑放大到局部，看相似度从高到低的产品列表；新记录无向量时不画假点。
2. **0:25–0:55：从需求出发。** 点击“保湿”，进入面霜价格与证据图。「横轴是同单位参考单价，纵轴是已收录的成分证据，不是成品实测效果。」指出页面真实覆盖和未入图原因。当前11款可绘制，20款目标未达，不把目录数当作可比较数。
3. **0:55–1:25：按自己的预算看差异。** 输入整件参考价上限，看到不符合条件的点淡显、坐标尺度保持。切品牌、单位与需求；说明g和ml不换算，较早参考价和按月目录价分别标记。
4. **1:25–1:55：形成候选。** 点开产品，看整件价格、规格、日期和来源；加入候选，固定入口提示已保留。再选一款，勾选两款进入对比。候选最多4款，不代替用户决定。
5. **1:55–2:35：追溯成分证据。** 先看同刻度的八方向，再点保湿贡献和来源。「每项能追到证据；完整标签与名称匹配是两种覆盖，缺失不补零。浓度估计不是披露值。」保留研究场景和限制。
6. **2:35–3:00：返回全景，说明边界。** 返回选品地图，预算和候选仍在；手机可通过列表完成同等操作。「我们展示选择范围和判断依据。下一步用相同商品、相同任务比较列表与地图的时间、理解差异和误读率，当前不声称已经证实更快。」

## 备用操作

- 全库搜索、同位记录展开、原空间相似产品与两组真实对比案例仍可使用。右侧百分比为原始余弦相似度，数值越大越接近，不是功效概率；筛选数量决定返回产品数。
- 探索设置保留UMAP/PCA、二维/三维、八方向证据空间；投影损失不等于产品效果差异。
- 无WebGL时显示真实不可用与重试；选品图、搜索、对比不依赖实时生成模型。

## 常见追问

- **指数高就是更有效吗？** 指数反映按既定规则汇总的已收录成分证据贡献，受资料覆盖影响，不能替代成品功效验证。
- **为什么没有百分制总分？** 当前资料不能支持普遍适用的产品综合能力评分；我们逐方向展示原始参考指数及来源。
- **为什么某项显示资料不足？** 当前没有合格资料可计入该方向，不代表该产品没有该功效。
- **为什么浓度不直接乘进主指数？** 全库浓度覆盖有限；首版把浓度作为独立资料维度，避免把缺数据直接解释为能力差。进一步浓度对照仍基于已有剂量服务，并保留估计语义。
- **同一篇研究会不会重复算？** 同成分、同方向多条断言只取最高合格权重；来源数量按证据 ID 去重。不同成分引用同一来源的情况可在贡献明细看到，不能将其误读为多项独立临床研究。
- **价格实时吗？** 是带来源与记录日期的历史参考值；不同单位不换算比较。
- **AI 在哪里？** 主展示强调可复算的证据指数与来源链；预计算嵌入用于相似检索。原站还保留问答与圆桌能力，展示页不要求用户与模型聊天。

## 演示前检查

- 确认私有创空间为 Running，并用所属账号登录；使用本地展示时确认 8008 API 与展示预览在线。
- 预跑两组真实案例，确认八方向、来源与单价；核对仍使用固定数据快照和 `evidence-index-v1`。
- 不承诺实时价格、全量证据覆盖或临床准确率；没有原文链接时如实说明。
- 保留“未评级”“资料不足”“浓度无法判断”“暂无价格”等缺失场景，不用虚构数据填图。
