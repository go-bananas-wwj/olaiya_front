# 颜鉴路演脚本

> 2026-10-20：当前改版主线为「产品全景 → 按需选品 → 两款对比」。上线状态和数量以实施验收记录及页面实时覆盖为准；数据门槛未达时不称全验收通过。

## 三分钟演示主线

1. **0:00–0:25：打开全景。** “传统列表一项项翻，难看清选择范围。颜鉴把真实护肤品放在同一张地图，每个点是一款产品；点开看图片、介绍和成分，再比较依据。”
2. **0:25–0:55：点‘从保湿开始’。** 展示同一批三维点重排为二维指标图的动画。“蓝色是已有保湿方向成分证据，金色仅有原产品宣称，灰色资料待补。全库资料数和图中数分别显示；没有价格也能先探索。”“横轴是已收录成分数，纵轴是保湿方向证据指数；成分数不是质量评分。”切换修护，看产品按该方向的真实指数移动，缺失放待补区域。
3. **0:55–1:35：点‘试试黑绷带’。** 查看图片、规格、来源简介与成分。调相似度90%→95%，球缩小、列表同步，外围全库背景保留；球面无内部网线，重合产品有小幅显示偏移。“半径按原始向量距离计算，球与列表同一标准；百分比是成分语义相似度，不是功效概率。滑块不移动产品。”点返回需求平面可退出。
4. **1:35–2:20：选A.G.E.对比。** 展示八方向原始证据指数，点保湿贡献成分，再开原始来源。“指数汇总已收录成分证据，受覆盖影响，不是成品实测效果。未知与零分分开；浓度估计不是披露值。”
5. **2:20–3:00：辅助价格比较与边界。** 返回平面，打开‘比较参考价格’，按品类、单位与预算查看已核验产品，保留来源和日期。“严格保湿面霜ml价格样本目前只有11款；全景记录、方向证据和可比价格是三种覆盖，不互相替代。下一步用相同任务和商品，与列表比较理解差异与操作时间。”

## 备用操作

- 首页“怎么操作”展示三步引导；手机通过搜索及产品列表完成同等选择，无横向溢出。
- 相似阈值读取完整原始索引，列表默认20款，可继续展开；缺少索引时显示真实不可用，不画虚假球。
- 探索设置保留UMAP/PCA、二维/三维、八方向完整证据空间，原始索引和冻结坐标不重算。
- 无WebGL显示不可用与重试；主流程不依赖实时生成模型。

## 常见追问

- **指数高就是更有效吗？** 指数反映按既定规则汇总的已收录成分证据贡献，受资料覆盖影响，不能替代成品功效验证。
- **为什么没有百分制总分？** 当前资料不能支持普遍适用的产品综合能力评分；我们逐方向展示原始参考指数及来源。
- **为什么某项显示资料不足？** 当前没有合格资料可计入该方向，不代表该产品没有该功效。
- **为什么浓度不直接乘进主指数？** 全库浓度覆盖有限；首版把浓度作为独立资料维度，避免把缺数据直接解释为能力差。进一步浓度对照仍基于已有剂量服务，并保留估计语义。
- **同一篇研究会不会重复算？** 同成分、同方向多条断言只取最高合格权重；来源数量按证据 ID 去重。不同成分引用同一来源的情况可在贡献明细看到，不能将其误读为多项独立临床研究。
- **价格实时吗？** 是带来源与记录日期的历史参考值；不同单位不换算比较。
- **AI 在哪里？** 主展示强调可复算的证据指数与来源链；预计算嵌入用于相似检索。原站还保留问答与圆桌能力，展示页不要求用户与模型聊天。

## 演示前检查

- 确认私有创空间为 Running，并用所属账号登录；使用本地展示时确认 8008 API 与展示预览在线。
- 预跑两组真实案例，确认八方向、来源与单价；核对仍使用固定数据快照和 `evidence-index-v1`。
- 不承诺实时价格、全量证据覆盖或临床准确率；没有原文链接时如实说明。
- 保留“未评级”“资料不足”“浓度无法判断”“暂无价格”等缺失场景，不用虚构数据填图。
