# 决赛路演脚本（8 分钟版 + 3 分钟电梯版）

> 基于调研 D 的制胜配方：30 秒一句话开场 → 现场对撞 → 三个高潮瞬间 → 数字收尾。

## 8 分钟版

### 0:00-0:30 开场（一句话立意）

「各位老师好。赛题说要守护内容的真实。我们想问一个问题：种草文里最伤钱包的是哪句话？不是 P 过的图——图可以鉴伪——而是那句**『这个成分能美白』**。图片可以 P，文献 P 不了。我们做的『成分真言』，就是美妆内容的**文献级鉴伪官**：30 秒核验一句功效宣称，每个结论都挂真实论文，每个不确定都明说。」

### 0:30-1:30 问题真实性与痛点（评委共鸣）

- 《化妆品功效宣称评价规范》强制要求宣称必须有依据——但没人替消费者核对。
- 现场一个例子：某爆款身体乳宣称「7 天美白」，成分表烟酰胺排第 3——它有文献支持，但**剂量够吗**？（停顿）这就是我们要回答的。
- 监管风向：《AI 生成合成内容标识办法》已施行，「AI 鉴真」是政策级热点。

### 1:30-3:30 现场对撞（核心演示，圆桌页）

「现在请各位老师随便说一个你们听过的产品或成分。」（预设兜底：烟酰胺/The Ordinary）

- 输入 → 圆桌四角色开始讨论（指着屏幕）：
  - 「成分专家在查产品库——它找到了 11 个成分和 3 个相似产品」
  - 「法规官在核对 NMPA 宣称摘要——它如实说『查不到摘要』，查不到本身也是信号」
  - 「文献核验官在查证据库——注意它说的：5% 开放标签人体研究，它主动指出这是弱证据」
  - 「剂量推断师在给浓度区间——注意它说『估计值』」
- 裁决卡出现：「**证据支持但剂量存疑**——五级判定，不是简单的是或否」

### 3:30-5:00 高潮一：点击引用跳 PubMed

「每个 [n] 都能点开——这是 Hakozaki 2002 年发表在《英国皮肤科学杂志》的论文，PMID 12100180，真实存在。**我们系统里没有一句话是没有出处的。**」

### 5:00-6:00 高潮二：每起效成本（78 倍）

「同一个功能，值多少钱？我们算了『每起效成本』：达到文献起效浓度的每日成本——The Ordinary 烟酰胺 **4 毛钱/天**，贵妇精华 **30 块/天**，**78 倍**。这才是消费者要的『敢说真话』。」

### 6:00-7:00 高潮三：诚实是架构（技术叙事给技术评委）

- 证据强制：数据库层强制每条断言挂真实文献，机器核验 PMID 100% 通过，**包括一条如实收录的阴性 RCT**。
- 剂量推断：约束采样估计浓度区间，锚点校准；「区间而非点值」，全程「估计值」。
- 三条件计分：引用正确率 97.5%、判定正确率 100%、总分 0.70——**无幻觉是可量化的**。
- 全链路跑在**昇腾 910B 国产算力**上，本地双通道，断网也能演示。

### 7:00-8:00 收尾（愿景 + 延续）

「美妆不缺 AI，缺敢说不知道的诚实。我们把诚实做成了架构。赛后我们会把剂量感知的核验 benchmark 和证据知识图谱开源、投稿——让『文献级鉴伪』成为美妆内容生态的基础设施。谢谢！」

## 3 分钟电梯版

1. (0:20) 立意：「我们核验种草文里最伤钱包的那句话——『这个成分能美白』。」
2. (0:50) 圆桌现场跑一个产品，四级/五级判定 + 点引用跳 PubMed。
3. (0:40) 78 倍每起效成本对比。
4. (0:40) 数字：97.5% 引用正确率、证据强制架构、910B 国产算力。
5. (0:20) 收尾：「把诚实做成架构，把文献级鉴伪做成基础设施。」

## 预设问答（尖锐问题清单，每题 30 秒答案）

1. **「浓度推断准吗？」**——「是区间不是点值，11 个品牌披露锚点上校准，稳健覆盖率 8/11；达不到的我们明说『无法判定』，不编造。」
2. **「和美丽修行有什么区别？」**——「它们的功效解读是无出处编辑文案，我们每条结论挂 PMID；它们相似度是黑盒，我们三级相似每级标置信口径。」
3. **「误判了谁负责？」**——「系统所有输出带估计语义和证据出处，用户可以当场复核——可验证性本身就是我们的责任设计。」
4. **「欧莱雅为什么需要这个而不是自己建？」**——「第三方中立核查是结构性的：巨头无法中立核查同行。对欧莱雅，这是『信任』叙事的基础设施，也是成分党消费者的沟通语言。」
5. **「赛题要多模态，你们图像呢？」**——「80% 深度在文献鉴伪，20% 覆盖图像：AI 生图检测已上线（实测 AI 图 97.7%、真图 8.8%），守住题面。」
6. **「数据从哪来？合法吗？」**——「全部 NMPA 法定公示数据（成分表+宣称摘要），合规采集带限流熔断；不碰电商爬虫；推断值全程标注估计。」
