# 产品空间：产品介绍与返回全景

2026-10-20，合并处理两条连续标注：选中后有直接返回操作；点选即可识别产品、看照片、宣称和成分。

## 交互

- 选中后在图上显示文字按钮“返回全景”；产品卡X、右上房子、图内Esc/Home以及点击点云空白处均可取消选择并恢复全景。旋转拖动、缩放、右键不会因空白命中而取消。
- 返回同时清除选中、隔离、产品详情、搜索与相似列表，并终止旧聚焦动画；保留当前地图模式和展示设置。异步晚到响应不能恢复已取消产品。
- 产品卡先展示来源参考图、品牌、完整名称、已知规格与参考价；再显示社区来源简介、已收录功效宣称和可点击成分。桌面默认展开，手机底部紧凑卡直接展示照片、简介摘要、宣称状态和前三项成分，点击产品名展开全部资料。成分可进入既有证据抽屉，保留来源与两款对比。
- 手机聚焦时只平移相机，使选中点位于底卡上方；图中名称避让卡片。源坐标与相似检索不变。

## 复用资料与来源边界

`build_product_presentations.py` 读取已有3629个INCIDecoder页面缓存，按真实产品ID、名称、品牌与原来源URL绑定生成3612条介绍元数据：3391条对应产品图地址、3597条最多25词的社区简介摘录。保留原采集时间与HTML SHA，不将导出日写为采样日；未提交原始HTML、数据库、索引或权重。

图片地址与原产品slug匹配，图片是来源参考图，不据此判断现售版本。仅抽样验收网络可访问性，不声称3391个地址全部在线可用；失败显示“图片暂不可用”，缺图显示“图片未收录”。原有四张本地案例图继续复用。

社区简介明确称“来源页简介／社区来源”，不冒充品牌官方说明或临床证据。功效宣称单独读取既有`ProductClaim`，不从简介、产品名称、成分功能或证据指数推断补写。宣称缺失明确显示未收录；展开时不截断已收录宣称。成分中文名继续来自已有知识库，无新翻译。

## API与部署

`GET /api/products/{id}`兼容增加可空`presentation`：图片URL、简介摘录、原来源、来源类别与原记录时间。服务缓存小型派生JSON；身份不符、文件缺失或异常结构均忽略，原产品资料仍可用。`CFZ_PRODUCT_PRESENTATIONS_PATH`统一配置，不新增数据库列、枚举或迁移。原产品空间、画像、Faiss与价格接口不变。

派生元数据随白名单`data/seed/`与源码发布到原私有免费CPU创空间。数据库、Faiss和固定布局版本保持现状，无需重发数据快照。

- 原站12项浏览器通过；展示版与原站生产构建通过。默认`web/`重建字节不变，Docker构建新的展示版。

## 独立审核

视觉／消费流程专家实看桌面、科颜氏与手机：旧底卡遮挡选中点属于阻断，已通过手机相机平移修复。实测选中点距卡顶约85px，返回操作显著，照片与成分提供有效识别；8.7/10通过，无剩余阻断。

工程／数据专家逐条核对3612条四字段身份、图片主机／slug及25词摘录上限，确认社区介绍与真实宣称分开、异步身份防护、取消／复位、手机相机平移均正确。两项非阻断建议（缺少source_url的异常资源、超过6项宣称的完整展示）已修正。

云端使用实际HTML／资源／API验收，核对原空间与两个案例原始近邻无变化，并核验新容器运行与持久数据恢复；截图与发布凭据保存在本地忽略目录。
