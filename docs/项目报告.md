# 成分真言 · 项目报告（黑客松提交版）

> 第二届欧莱雅「有意思青年–科技大 Fun 颂」美妆科技黑客松 · 赛题二：信任守护师
> 产品主线更新于 2026-10-20（北京时间）；下文历史评测结果仅作当时内部评测记录。

## 一句话

**「成分真言」是一个敢说真话的化妆品功效核验系统：把功效剂量做成知识表示的一等公民，让每个结论都有证据、每个证据都可查证、每个不确定都明说。**

## 我们守护什么

赛题说「伪造背书」。图片可以 P，文献 P 不了。种草内容里最伤消费者钱包的不是假图，而是**那句无法溯源的功效宣称**——「这个成分能美白」。我们核验的就是这句话。

这不是概念问题，是有法规牙齿的真问题：《化妆品功效宣称评价规范》（药监局 2021 年第 50 号公告）强制要求功效宣称必须有评价依据并公示摘要；市监局对「宣称抗老无法提供依据」持续开罚单。美妆内容生态缺一个「文献级鉴伪官」。

## 系统做什么

当前改版围绕“让消费者看清一类产品的选择范围，按需求与预算比较，再追溯依据”。主流程为：**三维看全景 → 选择保湿／修护等需求 → 二维比较参考单价与成分证据 → 收集至多4款候选 → 两款深入对比**。ModelScope发布状态与实际覆盖见[选品地图实施与验收](需求选品地图-实施与验收.md)，不将本地验证写成已上线。

三维保留原3749条真实成分表语义向量的固定UMAP／PCA坐标、搜索及原空间近邻。顶部用一段话说明用途，需求侧栏采用中性灰紫；视图以细灰网格、数值刻度和UMAP／PCA轴名呈现。完全重合点按产品ID稳定散开，偏移仅用于显示；点击优先选择屏幕最近点，Shift点击可主动展开附近记录，关闭展开可查原位分组。默认以全库作背景突出已核验面霜；新补资料没有向量时保留搜索入口，不伪造坐标。算法、维数与着色收进探索设置，手机首屏直接提供需求入口。八方向资料完整子集的旧证据空间仍可在设置中使用，缺失不补零。

二维按品类分开，以所选方向的成分功效证据指数为纵轴，以同单位人民币参考单价为横轴。两轴从零开始线性显示，品牌与整件预算筛选不改变尺度；g与ml分组，参考价带来源、真实读取日期，历史目录单独保留月份，不伪造具体采样日。入图只要求所选单方向有合格证据、完整来源成分表和可核验同单位价格，不再要求八方向完整。未入图记录逐条说明原因；未知不是零分。

用户可点选或框选，手机与键盘通过同等产品列表操作，候选跨筛选保留、超出条件时明确标记，再任选两款进入已有八方向对比。指数沿用 `evidence-index-v1`，同成分同方向最高合格权重相加，来源按真实证据ID去重、浓度单列；不输出成品效果、总分或性价比冠军。完整标签覆盖与知识库名称匹配覆盖分别展示，无法匹配的原文保留，不猜译、不补浓度。

本轮补充的是可追溯的官网商品事实，目录总数、完整成分表数量、可绘制数量分别统计。当前严格保湿面霜地图仅11款可绘制，尚未达到20款验收目标，不能用280款目录元数据替代该门槛。视觉本地R2为8.5/10（专家判断，非用户研究）。60秒找到3款候选、说明2项差异是待真人验证的目标，尚未声称地图优于列表。

## 三个技术支点

### 1. 功效剂量一等公民

安全/毒理侧剂量早已被结构化，但**本项目将研究浓度与剂量信息结构化进证据承载的知识表示**。我们把剂量贯穿到每一层：

- **知识库**：每条「成分→功效」断言挂起效浓度（真实文献）+ 证据层级（人体 RCT/开放试验/体外/动物/口服/复方，全部如实标注）
- **判定**：文献起效浓度 × 推断浓度区间 → 剂量达标判定（达标/存疑/不足/微量 ppm 级）
- **评测**：`verdict ∧ evidence ∧ dose` 三条件计分；目前评分仍以引用命中与措辞检查为主，尚不能等同独立人工金标准的正确率

### 2. 证据强制（evidence enforcement）

「每条断言必须挂证据来源」是**架构约束**：数据库层 NOT NULL + 外键阻断无关联证据的断言，但不保证证据内容真实或支持结论。paper 通道的前置工具核验 PMID 与 NCBI 标题，不能替代内容审核；加载器对核验凭据的强制检查仍需完善。口服、动物、体外和复方等条件需要逐条保留说明。

### 3. 功效指纹

既有剂量加权核验引擎与当前展示地图分开：当前地图不把未知浓度补入向量。产品不止由成分组成，更需要解释证据支持哪些方向。我们把产品投影到功效空间：功效维度 ×（推断剂量 × 证据强度）加权，跨品牌发现成分集合、估计剂量或功效证据方向相近的候选（不承诺功效等价），三级相似度全部标注置信口径。

## 内部评测记录与局限

历史 40 条内部回归集 + `verdict ∧ evidence ∧ dose` 三条件计分（本地 Qwen2.5-14B 实测）：

| 指标 | 分数 |
|---|---|
| E 引用正确率（挂对 PMID） | **97.5%** |
| V 判定正确率（含拒答） | **95%** |
| D 剂量措辞严谨度 | **77.5%** |
| 总分（三条件相乘） | **0.70** |

评测不是一次性的：第一轮发现剂量措辞只有 65%，改进 prompt + 在校验循环加「浓度数字强制限定语」规则后提升到 77.5%——**可测量、可改进、有数字**。

## 架构与部署

```
圆桌 Agent（四角色信息不对称分工，SSE 可视化）
  ├─ 模型层：Qwen2.5-14B（910B vLLM-Ascend 本地 ⇄ 云端 API 双通道）
  │    prompt RAG + schema 强制引用 → RARR 生成者-验证者循环（≤2 轮）
  ├─ 判定服务：D1 语义 / D2 剂量 / D3 理化透皮估计（D3 尚未接入圆桌工具流程）
  ├─ 表示层：配置的成分表嵌入（当前默认 Qwen3-Embedding-8B）+ 功效指纹 + 三级相似索引（Faiss）
  └─ 数据层：证据强制知识库（SQLite→可切 PostgreSQL）+ 采集管线
全链路国产化算力：华为昇腾 910B（vllm-ascend + torch_npu）
```

工程纪律：自动化测试覆盖数据层、接口、算法与降级；当前结果以测试输出为准；推断浓度与判定输出全程带「估计」语义。

## 演示路径

1. 打开三维产品空间，拖动旋转、缩放，切换二维与PCA，说明坐标由原始高维向量离线计算。
2. 点击一款产品：背景降灰、近邻橙色、原空间距离列表与产品资料同步；隔离／恢复，再搜索任意产品。
3. 点击近邻“比较”，或直接使用两款对比入口；查看完整八方向、贡献成分和原始来源。
4. 展示手机紧密邻域、任意A/B往返、缺证据／浓度／价格状态，不以投影或缺数据推导成品效果。
