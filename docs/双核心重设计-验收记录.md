# 颜鉴双核心重设计与验收

> 当前展示已由用户选定的[Embedding Projector版本](Embedding-Projector-实施与验收.md)替代。本文保留上一轮历史设计与当时验收结果。

日期：2026-10-18—19（北京时间）。本轮替代此前“地图为主、对比在下游”的设计：用户要求地图和两款对比同样突出，点更容易看清，界面清新且信息集中。

## 参考与取舍

实际查看了 [Gapminder Tools](https://www.gapminder.org/tools/) 的运行页面与 [Observable Plot Dot](https://observablehq.github.io/plot/marks/dot) 文档。借鉴大节点轮廓、缩放/全览、浅网格和清楚的数量表达。SkinSort借鉴来自用户给出的截图：稳定的双列产品身份、按区对齐的信息、渐进展开来源。SkinSort实时页面返回403，Nomic页面未成功加载，没有将它们写成已检查的在线参考。

没有复制品牌资产，也没有用装饰点替换真实产品。新配色为薄荷绿、深绿文字、蓝色候选和暖橙对比B，A/B及候选编号始终与颜色同时出现。

## 两个同级入口

- **产品地图**：默认真实参照产品及三款原始空间检索候选；可切换成分组成接近/功效证据接近；数字集合表示真实数量，单点最小半径5.5px，参照12px，候选9px，前景有白色隔离环。选中后镜头适配真实位置，可返回全库概览。手机以编号和图下名称对应，不在图中挤入长产品名。
- **两款对比**：共享顶部入口，两张紧凑身份卡后直接显示全部八方向。桌面1280×800中主图从约258px开始，八行在首屏内；390px手机同样完整显示八行。任意替换A/B、案例切换和地图往返保持产品ID及URL一致。来源、差异和价格继续可达。

手机地图详情为页面内区域，可通过“查看3款相近产品”定位；重叠集合保留可选择列表。原站入口保持兼容。

## 真实近邻口径

新增只读 `/api/products/{id}/space-neighbors?limit=3`，方法 `evidence-neighbors-v1`，输入是 `evidence-index-v1` 画像。参照至少三个已评分方向，且至少一项大于零；候选必须覆盖参照同一组已知方向。每方向以全库该方向最大有限值（最小尺度1）缩放，使用归一化均方根差；真实零保留，未知不补零，不乘未知浓度默认系数。距离相同时按产品ID稳定排序，不展示临床相似百分比。没有合格候选时如实显示原因，地图和两款对比仍可用。

地图投影和数据库未改写；二维近邻不用于候选排序。原L3指纹接口与新方法分开，原接口保持兼容。真实重叠投影仍可能遮挡，白环不等于保证所有点互不遮挡，需集合/列表入口。

## 本地验证

先补失败测试再实现。本轮全量pytest **838通过、1跳过**；前端逻辑 **16通过**；地图/对比浏览器 **23通过**；原站浏览器 **12通过**。原站与展示版生产构建均通过，`web/`仍提交默认原站构建。

覆盖真实零、无资料、未评级、缺浓度、缺价、不同单位、同产品、快速切换、候选接口失败、八方向同刻度、边界点、聚合集合真实成员和源对象不变。测试通过不代替视觉判断。

## 云端复审后的标签修正

首轮云端浏览器已核验两条主线、两个案例、任意A/B、两次点击来源与手机布局；数据、四款画像和布局签名不变，匿名API返回401。独立视觉专家随后发现桌面候选2的白底遮住候选3长名的一小段（P2），虽然侧栏仍可读，本次继续修复。

新增标签几何失败回归后实现统一避让：所有前景节点的白底范围先作为障碍，再布置标签，连同此前标签一起判碰撞。没有清楚空位时不画画布长名，侧栏编号与完整名保留；不移动真实产品坐标，不重新在编号上盖长名。前端逻辑增至16项，重新构建并复验展示浏览器，发布修正后的版本继续进行云端复核与重启验收。
