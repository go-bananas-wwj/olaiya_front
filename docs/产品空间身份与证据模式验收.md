# 产品空间：身份、重叠与双模式修正

用户指出重复名称、0.008的含义不清，以及语义嵌入与多维功效评估混淆。本轮沿用已选Google Embedding Projector三栏与两款对比，修正数据含义和选择体验。

## 交付口径

- 产品有唯一ID，向量和投影位置不保证唯一。固定快照3749个ID、3714个不同语义向量；31组共66条记录具有完全相同的成分输入及向量，不能据此认定同一产品或同配方。原全库有105组名称在旧短显规则下冲突，本轮不再删除括号版本／来源或`® With`描述。
- 不合并数据库、不猜区域版本、不添加ID制造向量差异、不抖动坐标。同位精确按当前投影坐标分组；视觉最多8个小计数，44px透明触摸区；其余组可通过汇总、悬停或点击展开。屏幕遮挡与同坐标分别解释。分组弹窗逐项保留完整名、品牌和记录ID。
- **成分组成相似**：既有4096维Qwen3-Embedding-8B成分表文本向量，UMAP/PCA 2D/3D。维度是模型隐含特征，不是浓度／价格／临床指标。默认余弦距离=1−余弦相似度，0.008意味着余弦相似度约0.992，不是成分重合率或功效比例。归一化欧氏距离沿用原公式。
- **功效证据相似**：`evidence-space-v1`，八方向指数来自`evidence-index-v1`，各方向除全库该方向最大值（至少1），取八维差值的均方根。只比较八方向全为有效scored的39款；真实零保留，3710款资料不完整仍可搜索／查来源／两款对比，但不进入地图或候选。不从缺失推断无功效，不乘未知浓度，不比较成品效果。
- 证据PCA由同一八维表示离线拟合，前三维解释约69.75%方差；39款是资料完整子集，不代表全库／市场功效分布。更换模式切换表示与排名；模式内切视图／轴／旋转不改变近邻。

## 失败测试与验证

先补失败测试：缺少新模式模块／按钮导致Node与浏览器失败；后端覆盖尚未实现的完整八维状态与投影验证；名称版本丢失、同位分组、主标签被挤掉和徽标过多均先复现再修复。

本地结果：全量pytest **880通过、1跳过**；Node逻辑 **42通过**。原八方向capability-profile逐项与39款新画像相同；1482个有向证据近邻按公式逐一复算。原站与展示版生产构建通过，默认`web/`随提交更新。

浏览器覆盖原空间旋转／点击／PCA轴／隔离／恢复／缺索引／WebGL中断、两款案例／任意ID／来源／缺价／未知浓度／不同单位；新增双模式、39/3749覆盖、版本后缀、晚到语义响应不能覆盖证据结果、单模式API失败、缺失方向不造点、同位组键盘展开与选择具体ID。最终展示版浏览器 **32项通过**，默认原站浏览器 **12项通过**。
