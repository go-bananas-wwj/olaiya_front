# 产品空间：局部探索与成分群组改版

2026-10-20，按用户五条页面标注实现。数据库、Faiss、价格与冻结投影坐标保持现状。

## 最终界面与交互

- 移除长方体、网格、刻度、UMAP/PC轴名、图内小字及技术图例；保留带可访问名称的标签、聚焦、复位按钮。
- 背景为雾紫灰渐变。成分群组使用八种固定颜色，图例置于左侧，不覆盖点云。
- 右侧改为“成分相似度／由高到低”和“筛选数量”。原始余弦分数以百分比显示，不做范围重新拉伸。证据模式明确称“证据画像相似度”，显示1减既有归一化RMS距离，不与成分余弦混用。
- 点击点或搜索选择产品，640ms平滑进入局部；图中最多四项名称，其他产品由列表查看。拖动、键盘、清除、更换产品、缩放、复位、尺寸变化或卸载均可取消旧动画；减少动态效果偏好直接定位。
- 手机选中后默认折叠产品卡，展开时显示原有完整资料；标签避让浮卡。复位与“显示全部”均可返回全景。二维需求图和两款证据对比继续可用。

## 群组数据依据

`data/tools/build_composition_families.py` 从固定原始Faiss读取3749条4096维向量，L2归一化后执行球面K-means（8组、种子20261020），20轮收敛。分组数为789、376、672、573、471、458、217、193。独立运行字节完全复现；相同向量均归入同组。

源索引SHA256：`1bfa3201e58d36c4c275389e0418dab86627fcff5c65b98be4a1314ebba928da`。

仅33KB产品ID与群组编号作为前端元数据提交，无权重或向量。`projection.source_index_sha256`为兼容新增字段；分组文件与当前索引不匹配时不着色，缺向量记录不补分组。A–H是统计群组编号，不命名为功效或临床分类。价格、品牌、投影位置没有进入聚类。相机聚焦与重合点显示展开均不影响原始向量检索。
