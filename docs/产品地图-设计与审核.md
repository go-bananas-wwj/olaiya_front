# 颜鉴产品地图：设计与多轮审核

日期：2026-10-18。范围：现有 ModelScope 私有展示版；默认原站入口与底层接口保持兼容。

## 产品与交互

一句话：**每个点，一款产品。先探索成分关系，再用证据核对。**

首屏是全库地图和搜索，不预选两款案例。用户可点选地图或搜索名称、品牌、备案号；资料侧栏/手机底部面板展示八方向证据及覆盖情况。功效方向→贡献成分→原始来源两次点击完成。任意两款可加入对比，返回地图保留选择、筛选与视图。可直接访问 `?compare=9,414`；示例仅为真实产品，不限制其他产品ID。

默认“成分地图”读取既有成分表语义嵌入的冻结二维投影，按所选证据方向着色。切换“证据坐标”可选择八个原始方向作为横纵轴；两轴均有资料才定位，其余产品仍保留在可检索列表。品牌筛选不重新拟合坐标。重叠点展开逐款列表，不用随机抖动伪造差异。

创新落在**全库探索→维度解释→证据核验**的联动，不宣称首创降维算法、临床平替或功效等价。界面收敛为地图、搜索、按需详情与对比托盘，不加入聊天、排行榜、装饰粒子或推断类别。

## 数据与算法决定

- 固定快照：3749 产品、113945 成分关联、2396 断言。价格只有36款、类别只有17款，不用它们构造默认空间，也不猜测缺失字段。
- 主图输入是4096维成分表语义向量，不含品牌或功效断言；当前全部产品都有成分表。按真实DB ID对齐，剔除本地索引27个过期ID。
- UMAP离线固定：`n_neighbors=15, min_dist=.15, metric=cosine, random_state=417, n_jobs=1, n_epochs=500`。精确相同向量先合并，拟合后展开，31组/35个重复观测保持同坐标。
- 全库原始10近邻平均保留率44.137%；200点样本trustworthiness约0.9643。PCA对照仅保留约12.01%方差、抽样10近邻召回约5.1%，因此没有作为默认地图。
- 二维仍失真。图上不把轴解释为实际功效、不把群落解释为功效类别；“找相似”调用原4096维检索，不能用屏幕距离排序。
- CLI独立重建与分析版本坐标、指标和完整JSON SHA-256一致。运行时不安装UMAP/Numba/torch、不现场拟合；冻结坐标仅约211KB。
- 八维完整资料只有39款，102款八维均无合格资料，故证据维度不补零。全库17997项scored、11460项no_evidence、535项unrated；11995个NULL保留。
- 批量数据与单品共用资格筛选、最高贡献和Decimal加和。全部3749款逐一对比，scores/statuses/三项覆盖计数0差异；重复关联不抬高指数。

## 多轮审核记录

| 轮次与独立专家 | 发现及处理 | 最终结论 |
|---|---|---|
| 第一轮：产品与信息可视化 | 地图占据首屏；不让案例主导；全库搜索、重叠列表、按需证据 | 方案采用 |
| 第一轮：降维算法 | PCA保留率低；验证UMAP、固定种子、精确向量去重、二次拟合复现 | 算法审核通过 |
| 第一轮：证据与后端架构 | 不补零；批量复用既有证据规则；未知产品保留入口 | 方案采用 |
| 第二轮：新视觉/产品专家 | P1小字号低对比→核心数值12px、正文加深；P2贡献展开不可见→面板内定位；手机specificity覆盖再次修复 | 实际重拍复验通过 |
| 第二轮：新证据/数学专家 | 全3749款画像等价、WAL失效实测通过；P2异常投影JSON可能500→补结构及有限值校验、8项失败回归 | 13项地图pytest通过，审核通过 |
| 第二轮：新工程/无障碍专家 | P2键盘第8项不可视→滚入候选视窗；快速切换、手机、重叠、gzip/304/SSE实测 | 独立复验通过 |
| 第三轮：新发布与综合产品专家 | 固定私有资源/校验/重启复用、Secret清理、依赖隔离、默认原站与展示版构建、空库 | 本地发布审核通过，无P0/P1/P2 |

审核不替代云端验收；发布后继续核验实际资源版本、图谱计数、交互及容器重启恢复。

## 研究依据

- [TensorFlow Embedding Projector](https://www.tensorflow.org/tensorboard/tensorboard_projector_plugin)：从嵌入空间探索与选择对象的交互参考。
- [UMAP官方复现说明](https://umap-learn.readthedocs.io/en/latest/reproducibility.html)：固定随机状态并避免不可复现的并行优化；本版发布冻结坐标。
- [Distill：How to Use t-SNE Effectively](https://distill.pub/2016/misread-tsne/)：降维图的群落、远距离及视觉形态可能误导，不能直接作领域结论。
- [scikit-learn PCA文档](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)：解释方差和线性投影对照依据。
