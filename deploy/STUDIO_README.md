# 颜鉴 · 产品嵌入空间与证据对比

3749款产品，成分组成与功效证据两个独立空间。

**产品空间 / 两款对比**是两个同级入口。

- **成分组成相似**：全库3749款，比较成分表文本语义，不混入价格或未知浓度。每个点对应真实产品记录。使用既有4096维成分表语义向量，离线计算UMAP和PCA二维／三维投影；支持旋转、平移、缩放和主成分轴切换。
- **功效证据相似**：八方向同轴使用全库最大值（至少1）缩放，原八维RMS距离检索，PCA二维／三维投影。只有39款资料完整，其余3710款保留搜索与对比；未知不补零。39款子集PCA三轴解释约69.75%方差，不代表全库或市场功效分布。
- 点击点：选中产品突出显示，其他点变灰，成分模式默认至多100个原始空间近邻（证据模式为其余38款）显示金橙色与可读名称；右侧同步产品列表和距离，画布右上显示产品资料。
- 可调整5—100个近邻，隔离选择、恢复全库、清除选择；搜索覆盖全库。保留名称里的版本／来源；同一投影位置显示紧凑计数并可展开记录。ID唯一不保证向量唯一，重叠不代表同产品或同配方，坐标不随机错开。
- 点击候选“比较”进入真实A/B对照；也可直接搜索任意两款。完整八方向共用刻度，保留贡献成分、来源、成分差异和同单位历史参考价格。
- 手机将两侧工具栏收进抽屉，保留三维点云和两款对比入口。

空间交互参考 [Google Embedding Projector](https://projector.tensorflow.org/)。颜鉴使用自己的产品数据与实现；没有打包Google示例数据。字体与渲染库许可见 `/licenses/README.txt`。

降维存在信息损失：本版UMAP三维的原始10近邻平均保留率约49.5%；PCA前三主成分解释约15.47%方差。坐标方向、距离和群落不是成品功效结论。右侧按各模式原始向量检索，不按屏幕位置排序；距离越小越接近，不是功效评分或成分重合率。成分模式支持余弦距离（1−余弦相似度）／归一化欧氏距离；证据模式使用八维缩放差值的均方根。

成分功效证据指数沿用 `evidence-index-v1`，不是成品实测效果。功能分类、法规、安全及供应商资料不作功效实证；未知浓度不补齐。价格保留来源与记录日期，ml/g不互换。

现有私有免费CPU创空间；主流程不依赖实时模型推理，运行时不拟合降维。数据库快照与原有接口兼容，三维坐标使用独立固定版本、启动校验及持久目录复用。
