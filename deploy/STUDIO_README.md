# 颜鉴 · 成分对照台

选择产品，找到成分相近的候选，对比共有／不同成分、参考价格与可追溯证据。

- 两组真实案例：黑绷带／A.G.E. 面霜，Serum 10／C E Ferulic。
- 成分重合与嵌入相似分别展示，价格独立排序，同单位才比较单价。
- 点击成分查看来源和证据局限；圆桌分别核验每款产品。

相似不代表功效等同。价格为历史采样，非实时售价。估计浓度不是实测值；功能分类、安全与法规资料不是临床功效实证。

本空间为私有验收版本。实时圆桌需要可用的云模型权限；缺少权限时明确提示，产品与成分对照仍可使用。
