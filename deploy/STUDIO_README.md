# 颜鉴 · 护肤品成分地图

每个点，一款产品。先探索成分关系，再用证据核对。

- 全库成分表语义地图：搜索产品或品牌、点选产品，查看八方向证据画像。
- 切换“证据坐标”，选择保湿、修护等原始证据维度。资料不足不补零，未定位产品仍可搜索和查看。
- 重叠位置展开逐款列表；任意两款可加入对比，核对贡献成分、来源与同单位参考价格。
- 功效方向 → 贡献成分 → 原始来源最多两次点击；方法与局限按需展开。

地图为冻结的UMAP二维投影，原始10近邻平均保留约44.1%；空间距离、方向和群落不代表配比或成品功效。相似候选按原始4096维检索，不能用屏幕距离排名。

成分功效证据指数沿用 `evidence-index-v1`，不是成品实测效果或有效率。功能分类、法规、安全和供应商资料不作功效实证；未知浓度明确标注。价格为历史参考，ml/g不互换。四款演示产品图对应已有成分来源页，仅作识别，不推断现售包装、版本或规格。

私有CPU验收版；主流程确定性运行，不需要实时模型生成。原站双列对比保留为地图下游流程。截图和各轮审核见源项目 `design-qa.md` 与 `docs/产品地图-设计与审核.md`。
