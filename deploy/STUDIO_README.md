# 颜鉴 · 护肤品选品地图

看清一类产品的选择范围，按需求与预算比较，再追溯成分证据。

**三维全景 → 需求平面 → 相似范围 → 两款深入对比。**

首页可直接点击“从保湿开始”或“试试黑绷带”，“怎么操作”提供三步说明。全库4,029条记录，3,749条有真实三维坐标；保湿方向全库3,190条成分证据记录，资料覆盖与图中数量分开显示。

- 产品空间保留3749条真实成分表语义向量的UMAP/PCA二维与三维坐标，保留基于原始成分向量的点色，不展示群组编号列表。新资料没有真实向量时保留搜索入口，不伪造坐标；探索设置分别显示全库记录数和可投影数。
- 点击保湿、修护、舒缓、抗皱等需求，同一批真实产品平滑重排为指标坐标：横轴“已收录成分数（项）”，纵轴为该需求的成分功效证据指数。八方向共用零起点线性刻度，切换需求按真实指数移动点；缺少资料放单独待补区域，不当零。这是可解释属性图，不把UMAP轴命名为功效。需求平面不以缺价排除产品，按成分证据、仅产品宣称、资料待补着色；横轴表示资料中已收录成分数量，不表示配方优劣；价格另行比较。可筛品类，未知品类明确保留。
- 选中产品进入“相似范围”：原始余弦相似度阈值对应半径sqrt(2×(1−阈值))的球，方向参考原图，距离使用原始向量；不把UMAP间距当作相似度。全索引候选一次读取，滑块改变球与列表，不改变点的位置；默认显示20条可继续展开。二维使用同口径圆形范围。相似球保留透明面与单一轮廓，球外全库背景保持可见；径向重合点采用受轮廓约束的小幅显示偏移，原始距离与阈值不改。
- “比较参考价格”保留严格核验的价格／证据图：同单位人民币参考单价与所选方向指数，两轴零起点、线性固定刻度，品牌与整件预算筛选只改变突出状态。g与ml不换算。
- 顶部介绍地图用途，白色通透页头和侧栏；上方先显示项目标题和介绍，三维采用透明画布与白色背景，无框线、刻度或轴名。点击产品平滑变为局部相似距离视图，最多显示四项名称；手机端先显示紧凑名称卡，点击展开资料。三维显示的X/Y/Z比例分别为1.12/1.10/2.10，以更开阔的斜视角和58°视场呈现；近点稍大、远点稍淡，原始投影与相似检索不受显示比例影响。二维价格／证据图不拉伸。完全重合点默认按产品ID稳定散开展示，原始坐标、相似度和排序保持不变；密集区点击直接选中最近的显示点。Shift点击可主动展开附近记录。二维价格图保持真实坐标并对同值点计数展开。点击可查看价格、规格、记录日期、贡献成分及来源；桌面可框选，手机与键盘可通过同等产品列表操作。
- 点选后直接查看来源参考图、名称、社区简介、已收录功效宣称和成分；简介与功效证据分开，缺图或缺宣称如实标注。图上“返回全景”、产品卡X、点击空白或图内Esc/Home可取消并恢复视角；手机底部资料卡与选中点分开。
- 候选夹最多4款，跨筛选保留并说明条件差异；任选两款进入完整八方向对比，再返回选品地图。两款对比也支持全库搜索和两个真实案例。
- 缺价、未知单位、缺少完整成分或方向证据的记录逐条说明原因，不放在零坐标。完整来源标签与知识库匹配覆盖分别展示，未匹配原文不补猜。

当前新补官网目录280款、9品牌，另复用既有记录；目录、完整标签与可绘制数量分别统计，不把样本称为整个市场。严格保湿面霜ml组目前仅11款可绘制，20款数据覆盖目标尚未达到；页面按实际数量展示。参考价不是实时成交价，较早参考价与按月历史目录价均保留日期语义。

指数沿用 `evidence-index-v1`：同成分同方向只取最高合格证据权重再求和，来源按证据ID去重、浓度单列。它受资料覆盖影响，**不是成品实测效果**。不输出综合总分、有效率或性价比冠军。法规、功能分类、安全及供应商资料不作功效实证，未知不补零。

探索设置仍提供成分组成相似与八方向证据相似。前者检索原4096维成分语义向量，以原生余弦相似度百分比降序展示；后者仅在八方向有合格资料的子集中使用同轴缩放RMS距离和离线PCA，相似度显示为1减RMS距离。投影存在信息损失，距离、群落、相近组成不代表同配方或成品功效等价。群组配色来自同一固定索引的球面K-means（8组、种子20261020），分组文件绑定索引SHA，缺少向量时不分组；标题与介绍布局参考 [EarthEmbeddingExplorer](https://modelscope.cn/studios/Major-TOM/EarthEmbeddingExplorer-Dense-Qwen3-VL-Embedding)，点色呈现参考 [Embedding Atlas](https://github.com/apple/embedding-atlas)。空间交互参考 [Google Embedding Projector](https://projector.tensorflow.org/)，没有打包其示例数据。字体与渲染库许可见 `/licenses/README.txt`。

私有免费CPU创空间，主流程使用确定性服务与固定数据／坐标资源，不依赖实时模型，不在线拟合降维。新快照写入独立持久目录，旧版本保留以便回滚。

本轮对比页统一深灰文字，产品A为蓝色、B为紫色，始终保留A/B标记。


本轮三维价格视图：需求指标图现为可旋转三维，X为已收录成分数，Y为所选方向成分证据指数，Z为人民币整件参考价。未收录价格位于独立后层，不当零；来源、日期与规格仍在产品卡查看。首次进入全景时点云由中心展开并伴随轻微视角转动，遵从减少动态效果偏好。左侧探索设置整块移除，保留需求、搜索和对比主操作。原始投影、证据指数与相似检索数据未改变。


相似筛选交互更新：点选仅显示产品卡并按显示距离连续渐隐周围点，不自动聚焦或进入相似球。阈值默认75%，按“开始相似度筛选”后才请求全索引并进行一次视图切换；修改阈值后按“应用筛选”生效。切换产品或清除会撤销旧筛选，旧响应不得覆盖新选择。


本轮需求图默认二维功效平面，缺价格不妨碍查看成分证据；三维价格图通过工具栏切换，仅绘制方向证据与价格都存在的产品。缺失记录进入可搜索的“未入图”列表，不占用零轴或负轴；真实0仍保留在零轴。左侧资料分类按钮移除。功效切换先由当前平面展开到固定的三维成分全景（保留短暂停留与原分布颜色），再进入目标平面；快速切换从当前实际显示位置取消旧动画，最终只保留最新需求。
