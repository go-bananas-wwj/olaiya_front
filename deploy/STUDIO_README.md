# 颜鉴 · 成分地图与两款对比

探索成分与证据的相近之处，一键比较两款产品。

**产品地图 / 两款对比**是两个同级入口，均可直接使用。

- 产品地图覆盖3749款产品；搜索产品或品牌，选参照产品，查看三个真实相近候选。数字圆圈表示集合中的产品数量，放大或展开列表可逐款选择。
- 候选支持“成分组成接近”和“功效证据接近”；连线对应实际检索结果，不按二维屏幕距离排名。匹配方法与局限按需展开。
- 点击候选“与它对比”，或直接进入“两款对比”搜索替换任意A/B；产品身份和完整八方向同刻度条形图提前呈现，返回地图保留所选产品。
- 点击功效方向，再点击贡献成分的“查看来源”，最多两次点击核对原始证据；成分差异、完整成分表及参考价格在图表之后。
- 薄荷绿与蓝色标识参照和候选，对比A/B使用绿色与暖橙色，同时保留文字标签。手机通过编号图例和页面内结果区展示，无需悬停。

地图为冻结的UMAP二维投影，原始10近邻平均保留约44.1%；空间距离、方向和群落不代表配比或成品功效。成分组成候选按原始4096维向量检索；功效证据候选使用 `evidence-neighbors-v1`，在参照产品已有合格资料的同一组方向上比较，缺资料不补零，不是临床相似度。

成分功效证据指数沿用 `evidence-index-v1`，不是成品实测效果或有效率。功能分类、法规、安全和供应商资料不作功效实证；未知浓度明确标注。价格为历史参考，ml/g不互换。演示产品图对应已有成分来源页，仅作识别，不推断现售包装、版本或规格。真实重叠坐标可能遮挡，可通过集合与列表选择。
