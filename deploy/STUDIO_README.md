# 颜鉴 · 护肤品选品地图

看清一类产品的选择范围，按需求与预算比较，再追溯成分证据。

**三维全景 → 按需选品 → 收集候选 → 两款深入对比。**

- 产品空间保留3749条真实成分表语义向量的UMAP/PCA二维与三维坐标，默认突出已核验面霜样本。新资料没有真实向量时保留搜索入口，不伪造坐标；页面分别显示全库记录数和可投影数。
- 点击保湿、修护、舒缓、抗皱等需求，进入按品类分组的二维图：横轴同单位人民币参考单价，纵轴该方向的成分功效证据指数。两轴零起点、线性固定刻度，品牌与整件预算筛选只改变突出状态。g与ml不换算。
- 点击点查看价格、规格、记录日期、贡献成分及来源；同坐标计数展开，不随机错开。桌面可框选，手机与键盘可通过同等产品列表操作。
- 候选夹最多4款，跨筛选保留并说明条件差异；任选两款进入完整八方向对比，再返回选品地图。两款对比也支持全库搜索和两个真实案例。
- 缺价、未知单位、缺少完整成分或方向证据的记录逐条说明原因，不放在零坐标。完整来源标签与知识库匹配覆盖分别展示，未匹配原文不补猜。

当前新补官网目录280款、9品牌，另复用既有记录；目录、完整标签与可绘制数量分别统计，不把样本称为整个市场。严格保湿面霜ml组目前仅11款可绘制，20款数据覆盖目标尚未达到；页面按实际数量展示。参考价不是实时成交价，较早参考价与按月历史目录价均保留日期语义。

指数沿用 `evidence-index-v1`：同成分同方向只取最高合格证据权重再求和，来源按证据ID去重、浓度单列。它受资料覆盖影响，**不是成品实测效果**。不输出综合总分、有效率或性价比冠军。法规、功能分类、安全及供应商资料不作功效实证，未知不补零。

探索设置仍提供成分组成相似与八方向证据相似。前者检索原4096维成分语义向量；后者仅在八方向有合格资料的子集中使用同轴缩放RMS距离和离线PCA。投影存在信息损失，距离、群落、相近组成不代表同配方或成品功效等价。空间交互参考 [Google Embedding Projector](https://projector.tensorflow.org/)，没有打包其示例数据。字体与渲染库许可见 `/licenses/README.txt`。

私有免费CPU创空间，主流程使用确定性服务与固定数据／坐标资源，不依赖实时模型，不在线拟合降维。新快照写入独立持久目录，旧版本保留以便回滚。
