# 颜鉴 · 护肤品功效证据对比

选两款产品，看保湿、抗皱、修护等方向有哪些成分和证据支持。

- 两组真实案例：黑绷带／A.G.E. 面霜，Serum 10／C E Ferulic。
- 八个功效方向共用刻度，点击任一方向查看贡献成分与真实来源。
- 成分功效证据指数 = 各成分在该方向的最高合格证据权重之和；浓度资料单独呈现。
- 共有／差异成分和同单位参考单价单独对照；资料不足明确展示，不补零。
- 找相似产品通过辅助入口打开，主流程使用确定性计算，无需聊天或实时模型生成。

相似不代表功效等同。价格为历史采样，非实时售价。估计浓度不是实测值；功能分类、安全与法规资料不是临床功效实证。

本空间为私有验收版本。方法版本为 `evidence-index-v1`；指数受资料覆盖影响，不是成品实测功效、有效率或综合质量评分。

界面采用白底双列连续对照：产品参考图与来源、功效证据、贡献成分、成分对照、参考价格、成分解释和相似候选。八方向先展示四项，可展开全部；共享成分以紫色高亮，支持只看差异及紧凑视图，滚动时保留两款产品身份。

四款演示产品的图片对应各自 INCI Decoder 成分来源页面，仅供产品识别；图片出处与校验摘要保留在 `frontend/src/showcase/productPhotos.json`。其他产品没有匹配图片时如实提示。资料收录勾选不是安全认证；不展示无来源的评分、用户评价或功效标签。
